Drupal 11 Custom Module: Article Workflow Summary

Goal: Build a Drupal 11 module to manage an editorial workflow for the "Article" content type, including a dashboard, email notifications, and access control for Editors.

1. Create a Workflow

What: Set up a workflow called "Article Editorial Workflow" with three states:

  • Draft
  • Needs Review
  • Approved

Details:

  • Apply to the Article content type.
  • Only "Editor" role users can move articles to Approved.

2. Send Email Notifications

What: Send an email when an article is set to "Needs Review."

Details:

  • Email includes:
    • Article title
    • Article URL
    • Username of the person who changed the state
  • Use a custom service for email sending.
  • Implement using an EventSubscriber to listen for state changes.

3. Build a Dashboard

What: Create a page at /admin/content/needs-review-dashboard showing articles in "Needs Review."

Details:

  • Display a table with:
    • Title (linked to article)
    • Author
    • Last Updated
    • Operations (e.g., edit links)
  • Use Entity Query API to fetch articles.
  • Return table as a renderable array in a controller.

4. Control Access

What: Restrict dashboard access to users with the "Editor" role.

Details:

  • Create a custom permission: View Needs Review Dashboard.
  • Assign to Editor role.
  • Enforce access using:
    • A custom AccessCheck service, or
    • An _access callback in the routing file.
  • Non-Editors see a 403 (Access Denied) error.

5. Define a Custom Permission

What: Create a permission named View Needs Review Dashboard.

Details:

  • Define in *.permissions.yml file.
  • Assign to Editor role.

6. Follow Coding Standards and Document

What: Write clean code and provide documentation.

Details:

  • Use Drupal Coding Standards and PSR-4 namespacing.
  • Add Docblocks to all classes and methods.
  • Create a README.md explaining:
    • Module setup
    • Workflow assignment
    • Permission management
    • Testing instructions

7. Package as a Recipe (Optional)

What: Create a Drupal Recipe to make the module reusable.

Details:

  • The Recipe should:
    • Set up the workflow and assign to Articles.
    • Create and assign the custom permission.
    • Register the dashboard route.
    • List dependencies.
  • Include instructions to apply the Recipe.

8. Optional Bonus

What: Add a settings form to configure the email recipient for notifications.

9. Folder Structure and Files

What: Organize the module properly.

Details:

  • Use folders like src/EventSubscriber and src/Controller.
  • Define route in *.routing.yml.
  • Define permission in *.permissions.yml.
  • Register EventSubscriber in *.services.yml.

10. Testing Checklist

Ensure:

  • Workflow is set up and restricts approvals to Editors.
  • Emails are sent for "Needs Review" transitions.
  • Dashboard shows only "Needs Review" articles, accessible only to Editors.
  • Code follows standards, no deprecated APIs.
  • Documentation is clear and complete.

Key Points for Beginners

  • Module Name: Use something like article_workflow.
  • Key Components:
    • Workflow: Use Drupal’s Workflow module (in core).
    • EventSubscriber: For email notifications.
    • Controller: For the dashboard.
    • Access Control: Use permissions and access checks.
    • Recipe: Bundle configuration in a YAML file.
  • Start Small:
    1. Create module skeleton (.info.yml).
    2. Define the workflow.
    3. Build the dashboard route and controller.
    4. Add the EventSubscriber for emails.
    5. Implement permissions and access control.
    6. Write the Recipe and documentation.
